# Circularity Software Engineering

## Description
The Software Engineering project focuses on Gradle for version control, CI/CD pipelines, a project wiki, Scrum methodology, and JUnit testing. It emphasizes agile practices, iterative development, and quality assurance through automated testing, preparing students for real-world challenges in collaborative software development.

## Features
- **Version Control**: Managed using Gradle.
- **CI/CD**: Implemented with pipelines for continuous integration and deployment.
- **Documentation**: Comprehensive project wiki.
- **Methodology**: Scrum methodology for agile practices.
- **Testing**: Automated testing with JUnit to ensure high-quality software.
