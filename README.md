# Circularity Software Engineering

## Description
The Circularity Software Engineering project is designed to provide a comprehensive learning experience in modern software engineering practices. This project focuses on various aspects including version control with Gradle, CI/CD pipelines, a detailed project wiki, Scrum methodology for project management, and rigorous testing with JUnit. The project aims to prepare students for real-world challenges in collaborative software development by emphasizing agile practices, iterative development, and quality assurance through automated testing.

## Project Overview
This project is part of a software engineering course that introduces students to the following key concepts:
- **Version Control**: Using Gradle, students manage dependencies, build configurations, and project versioning.
- **CI/CD Pipelines**: Implementing continuous integration and deployment pipelines to streamline the development process.
- **Project Wiki**: Maintaining a detailed project wiki for documentation and collaboration.
- **Scrum Methodology**: Emphasizing iterative development and agile practices using Scrum.
- **Automated Testing**: Ensuring software quality with JUnit testing.

## Features
- **Version Control**: Managed using Gradle.
- **CI/CD**: Implemented with pipelines for continuous integration and deployment.
- **Documentation**: Comprehensive project wiki.
- **Methodology**: Scrum methodology for agile practices.
- **Testing**: Automated testing with JUnit to ensure high-quality software.

## Technologies Used
- **Java**: The primary programming language for the project.
- **Gradle**: For build automation and dependency management.
- **JUnit**: For writing and running automated tests.
- **CI/CD Tools**: GitLAB Actions for continuous integration and deployment.
- **Agile Tools**: GitLAB for Scrum project management.
